Este projeto é uma **aplicação web de conversão de moedas**, criado para treinar **HTML, CSS e JavaScript**.  
O diferencial é a **atualização dinâmica de valores e imagens das moedas**, tornando a experiência do usuário mais interativa.

## 🎯 Objetivos do projeto

- Criar uma **interface limpa e intuitiva** para conversão de moedas  
- Treinar **CSS avançado e layout responsivo**  
- Implementar **JavaScript para lógica de conversão e atualização dinâmica**  
- Melhorar a experiência do usuário com **feedback visual em botões e footer interativo**
